# 지침 분량 줄이기 실험안

작성일: 2026-11-03. 실행하지 않은 실험안이다. 지침을 줄여도 결과가 유지된다는 근거는 아직 없으므로, 검증 전에는 `skills/geulppal`에 적용하지 않는다.

## 왜 보나

2차 새 확인용 다듬기(12개 × 2회)에서 글빨 0.5.2는 글빨 없이 다듬을 때보다 비용 추정치가 2.27배(0.044달러 대 0.100달러), 시간 중앙값이 1.71배(9.1초 대 15.6초)였다. 입력 토큰 중앙값은 9,895개에서 20,064개로 늘었다. 스킬 본문을 읽는 비용이 크다.

지금 `SKILL.md`는 약 18.7KB이고, 그중 "한국어 독자가 멈칫하는 곳"(예시 표 포함)이 약 9,800자다. 참고 문서 두 개(약 19.7KB)는 필요할 때만 읽는다.

## 후보

| 후보 | 바꾸는 것 | 그대로 두는 것 |
|---|---|---|
| L1 | 낱말대로 옮긴 말 표, 번역투 표, 과장 표를 `references/editing-examples.md`로 옮기고, 본문에는 고치는 순서와 판단 기준만 남긴다 | 이름은 옮기지 않기, 뜻 지키기, 출력 방식 |
| L2 | L1에 더해 영어 글 절과 완성 점검을 줄인다 | 뜻 지키기, 출력 방식 |

## 비교 방법

1. 실험 전에 처음 보는 다듬기 사례를 새로 만들어 커밋한다(개발 답변과 일상 답변, 원문 끝에 제안이 있는 답변 포함).
2. 글빨 없음, 현재 버전, L1, L2를 같은 CLI 버전으로 2회씩 실행한다. `preserve-cases.json`도 함께 돌린다.
3. 비교 항목: 원문 표시가 그대로 남은 경우, 다듬은 글을 다시 판정한 표시 수, 의미 보존, 입력 토큰·비용·시간(`natural.mjs polish-stats`, `report.mjs`).
4. 채택 기준(실행 전에 정한다): 의미 보존이 현재 버전보다 낮지 않고, 그대로 남은 경우가 현재 버전보다 늘지 않으며, 비용이 줄어든 경우에만 채택한다. 차이가 판정의 흔들림 안이면 현재 버전을 유지한다.

## 하지 않을 것

- 실험 결과 없이 본문을 줄여 배포하지 않는다.
- 표시한 곳의 수를 품질 점수로 소개하지 않는다.
