# 사례별 결과: 블로그·에세이 개발용

[← 벤치마크 개요](../../README.md)

사례 이름을 누르면 요청, 메모, 조건별 결과, 판정 이유를 볼 수 있습니다. 근거 판정 칸은 조건마다 통과한 회차 수입니다(글빨 없음 · 글빨 0.4.1 · 0.4.3-r1 후보 · 0.4.4-r1 후보).

품질 비교 칸은 회차별 결과입니다. 이름이 적힌 쪽이 우세, `같음`은 차이 없음, `엇갈림`은 순서를 바꾸면 판정이 바뀐 경우, `제외`는 한쪽 이상이 근거 판정에 실패해 비교하지 않은 경우입니다.

자동으로 만든 페이지입니다. 판정은 모두 모델(`claude-opus-5-5`)이 했고 사람의 평가가 아닙니다.
