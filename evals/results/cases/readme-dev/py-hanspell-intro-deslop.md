## 원문

> # py-hanspell
>
> **네이버 맞춤법 검사기를 파이썬에서 그대로, 간편하게.**
>
> py-hanspell은 네이버 맞춤법 검사기를 활용한 파이썬용 한글 맞춤법 검사 라이브러리입니다. 몇 줄의 코드만으로 한글 문장의 맞춤법을 점검할 수 있어, 글을 다루는 다양한 프로젝트에 손쉽게 녹여 낼 수 있습니다.
>
> 파이썬 2.7과 3.4를 모두 지원합니다.
>
> ---
>
> ## 설치
>
> 설치 방법은 두 가지입니다. 환경에 맞는 쪽을 선택해 보세요.
>
> ### 방법 1. pip로 설치하기
>
> 가장 간단한 방법입니다. 커맨드 라인에 아래 명령어를 입력하면 설치가 자동으로 진행됩니다.
>
> ```bash
> $ pip install py-hanspell
> ```
>
> ### 방법 2. GitHub 저장소에서 직접 설치하기
>
> 이 GitHub 저장소를 로컬에 clone 하거나, 우측 메뉴에서 zip 파일로 내려받은 뒤 로컬 커맨드 라인에서 아래 명령어를 실행합니다.
>
> ```bash
> $ python setup.py install
> ```
>
> 설치 과정 없이 사용하고 싶다면, hanspell 폴더를 자신의 프로젝트 폴더 안에 그대로 포함시키는 방법도 있습니다.
>
> ### 필요한 라이브러리
>
> - requests
>
> ---
>
> ## 라이브러리 사용에 대한 안내
>
> 이 라이브러리는 네이버 한글 맞춤법 검사기를 바탕으로 만들어졌습니다.
>
> 모든 결과 및 데이터에 대한 저작권과 책임은 네이버 주식회사에 있습니다. 또한 라이브러리를 상업적으로 사용하거나 불법적인 용도로 활용하여 발생한 문제에 대해서는 개발자가 어떠한 책임도 지지 않습니다.
>
> ---
>
> ## 변경내역
>
> - **버전 1.1**: list 타입으로 데이터를 주고받는 기능을 지원하며, 처리 속도를 향상했습니다.
> - **버전 1.0**: 첫 버전을 릴리즈했습니다.
