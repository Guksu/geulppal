## 원문

> # KcBERT: Korean comments BERT
>
> ## 📢 Updates
>
> ### 2022.11.07 — 더 크고 풍부해진 텍스트 데이터셋 공개
>
> KcELECTRA v2022 학습에 사용된 **확장 텍스트 데이터셋(v2022.3Q)**을 공개합니다.
>
> - 데이터 용량은 기존 11GB에서 **45GB**로, 데이터 규모는 기존 0.9억 건에서 **3.4억 건**으로 늘어났습니다. 기존 v1 데이터셋과 비교하면 약 **4배** 커진 규모입니다.
> - 데이터셋은 아래 링크에서 확인하실 수 있습니다.
>   👉 https://github.com/Beomi/KcBERT/releases/tag/v2022.3Q
>
> ### 2022.10.08 — KcELECTRA-base-v2022, 새 이름으로 만나보세요
>
> KcELECTRA-base-v2022(구 dev) 모델의 이름이 변경되었습니다.
>
> - 기존 KcELECTRA-base(v2021)와 비교했을 때, 대부분의 downstream task에서 **~1%p 수준의 성능 향상**을 확인했습니다.
>
> ### 2022.09.14 — Preprocessing 코드 업데이트
>
> emoji가 v2.0.0으로 업데이트됨에 따라 Preprocessing 코드가 일부 변경되었습니다.
>
> ### 2021.04.07 — KcELECTRA 릴리즈! 🤗
>
> KcELECTRA가 정식으로 공개되었습니다.
>
> - KcELECTRA는 더 많은 데이터셋과 더 큰 General vocab을 바탕으로 학습하여, KcBERT 대비 **모든 태스크에서 더 높은 성능**을 보여 줍니다.
> - 아래 GitHub 링크에서 직접 사용해 보세요.
>   👉 https://github.com/Beomi/KcELECTRA
>
> ### 2021.03.14 — 논문 인용 표기와 성능 지표 추가
>
> - KcBERT 논문의 인용 표기(bibtex)를 추가했습니다.
> - KcBERT-finetune의 Performance score를 본문에 추가했습니다.
