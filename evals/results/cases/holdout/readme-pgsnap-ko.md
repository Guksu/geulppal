## 원문

> # pgsnap
>
> pgsnap은 PostgreSQL 데이터베이스의 백업을 혁신적으로 간편하게 만들어 주는 강력한 도구입니다. 오늘날과 같이 데이터가 무엇보다 중요한 시대에 있어서, 백업은 선택이 아닌 필수라고 할 수 있습니다. pgsnap은 이러한 백업 작업을 자동화하는 것을 가능하게 해 줍니다. 즉, pgsnap을 사용하면 백업을 자동으로 수행할 수 있습니다.
>
> ## 설치
>
> pgsnap의 설치는 매우 쉽고 간단합니다. Python 3.10 이상이 설치되어 있는 환경에서 아래의 명령어를 실행하는 것을 통해 설치를 진행할 수 있습니다.
>
> ```bash
> pip install pgsnap==0.8.2
> ```
>
> 설치가 완료된 이후에는 `pgsnap --version` 명령을 실행하여 설치가 정상적으로 이루어졌는지에 대한 확인을 할 수 있습니다.
>
> ## 설정
>
> pgsnap은 기본적으로 현재 디렉터리의 `pgsnap.yaml` 파일을 읽어 들입니다. 다른 위치의 파일을 사용하고자 하는 경우에는 `--config` 옵션을 통하여 경로를 지정해 주시면 됩니다. 주요한 설정 키는 다음과 같습니다.
>
> - `target_dir`: 백업 파일이 저장될 디렉터리입니다. 기본값은 `./backups`입니다.
> - `retention_days`: 백업 파일을 보관하는 기간(일)입니다. 기본값은 `7`이며, `0`으로 설정할 경우 오래된 백업을 삭제하지 않습니다.
> - `compression`: 압축 방식입니다. `zstd`, `gzip`, `none` 중 하나를 선택할 수 있으며 기본값은 `zstd`입니다.
>
> ## 알려진 한계
>
> 현재 버전에 있어서 pgsnap은 증분 백업이 아니라 전체 백업만 지원합니다. 따라서 데이터베이스의 크기가 큰 경우에는 백업에 시간이 오래 걸릴 수 있습니다. 내부 테스트에서는 약 50GB 크기의 데이터베이스를 `zstd`로 백업하는 데 약 40분이 소요되었습니다(8코어, NVMe SSD 환경). 또한 Windows 환경은 공식적으로 지원하지 않으며, 테스트도 진행하지 않았습니다. 증분 백업 기능은 1.0 버전에서 추가하는 것을 검토하고 있으나 일정은 아직 정해지지 않았습니다.
>
> ## 마치며
>
> pgsnap은 여러분의 소중한 데이터를 지키는 든든한 파트너가 되어 드릴 것입니다. 지금 바로 pgsnap과 함께 안전한 백업 생활을 시작해 보세요! 문의 사항은 https://github.com/example/pgsnap/issues 에 남겨 주시기 바랍니다.

> # pgsnap
>
> pgsnap은 PostgreSQL 데이터베이스 백업을 자동화하는 도구입니다.
>
> ## 설치
>
> Python 3.10 이상이 설치된 환경에서 아래 명령으로 설치합니다.
>
> ```bash
> pip install pgsnap==0.8.2
> ```
>
> 설치가 끝나면 `pgsnap --version`으로 정상 설치됐는지 확인할 수 있습니다.
>
> ## 설정
>
> pgsnap은 기본적으로 현재 디렉터리의 `pgsnap.yaml` 파일을 읽습니다. 다른 위치의 파일을 쓰려면 `--config` 옵션으로 경로를 지정합니다. 주요 설정 키는 다음과 같습니다.

> - `target_dir`: 백업 파일이 저장될 디렉터리입니다. 기본값은 `./backups`입니다.

> - `compression`: 압축 방식입니다. `zstd`, `gzip`, `none` 중 하나를 선택할 수 있으며 기본값은 `zstd`입니다.
>
> ## 알려진 한계
>

>
> ## 문의
>
> 문의 사항은 https://github.com/example/pgsnap/issues 에 남겨 주시기 바랍니다.
>
> ---
>
> 바꾼 내용은 다음과 같습니다.
