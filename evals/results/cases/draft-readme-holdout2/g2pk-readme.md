> # g2pK: 한국어 Grapheme-to-Phoneme 변환기
>
> g2pK는 한국어 텍스트를 실제 발음대로 바꿔 주는 규칙 기반 G2P(Grapheme-to-Phoneme) 파이썬 패키지입니다.
> 표준 발음법의 규칙을 구현했고, 영어 단어·아라비아 숫자·관용적 발음이 섞인 문장도 처리합니다.
> 음성 합성(TTS)이나 음성 인식의 전처리 단계에서 쓰기 좋습니다.
>
> ```python
> >>> from g2pk import G2p
> >>> g2p = G2p()
> >>> g2p("어제는 날씨가 맑았는데, 오늘은 흐리다.")
> ```
>
> ## 주요 기능
>
> - **표준 발음법 구현**: 연음, 경음화, 비음화, 유음화, 구개음화, 자음군 단순화 등을 규칙표(`table.csv`)와 예외 처리로 적용합니다.
> - **형태소 분석 활용**: MeCab으로 품사를 태깅해, 관형사형 어미 `-ㄹ` 뒤의 경음화나 용언 어간 받침 처리처럼 문법 정보가 필요한 규칙을 적용합니다.
> - **영어 → 한글 변환**: CMU 발음 사전(`cmudict`)을 이용해 영어 단어를 한글 발음으로 바꿉니다. (예: `file` → `파일`)
> - **숫자 읽기**: 아라비아 숫자를 문맥에 맞게 한글로 풀어 씁니다. (예: `3개` → `세개`)
> - **관용 표현 사전**: 규칙만으로 처리하기 어려운 사이시옷 합성어, `mp3`, `ml`, `%` 같은 표기를 `idioms.txt`로 처리합니다.
> - **규칙 해설 출력**: `verbose=True`를 주면 어떤 규칙이 적용되어 발음이 바뀌었는지 단계별로 보여 줍니다.
>
> ## 설치
>
> Python 3.6 이상이 필요합니다.
>
> ```bash
> pip install g2pk
> ```
>
> 소스에서 직접 설치하려면 저장소를 내려받은 뒤 다음을 실행합니다.
>
> ```bash
> pip install .
> ```
>
> ### 의존 패키지
>
> 아래 패키지는 `pip`가 함께 설치합니다.
>
> | 패키지 | 용도 |
> | --- | --- |
> | `jamo` | 한글 음절 ↔ 자모 분해·조합 |
> | `nltk` | CMU 발음 사전 로드 |
> | `konlpy` | 한국어 자연어 처리 도구 |
> | `python-mecab-ko` | 형태소 분석(MeCab) |
>
> `cmudict` 데이터가 없으면 `g2pk`를 처음 import할 때 NLTK가 자동으로 내려받으므로, 최초 1회는 인터넷 연결이 필요합니다.
> MeCab 초기화에 실패하면 `pip install python-mecab-ko`를 안내하는 예외가 발생합니다.
>
> ## 사용법
>
> ### 기본 사용
>
> ```python
> from g2pk import G2p
>
> g2p = G2p()
> print(g2p("나의 친구가 mp3 file 3개를 다운받고 있다"))
> ```
>
> `G2p` 객체는 생성할 때 MeCab과 사전을 로드하므로, 여러 문장을 처리할 때는 한 번 만든 객체를 재사용하세요.
>
> ### 옵션
>
> `G2p` 객체를 호출할 때 다음 인자를 쓸 수 있습니다.
>
> ```python
> g2p(string, descriptive=False, verbose=False, group_vowels=False, to_syl=True)
> ```
>
> | 인자 | 기본값 | 설명 |
> | --- | --- | --- |
> | `string` | – | 변환할 입력 문장 |
> | `descriptive` | `False` | `True`이면 규범 발음 대신 실제 언중의 발음 경향을 반영합니다. 예를 들어 조사 `의`를 `에`로, 첫음절이 아닌 `의`를 `이`로, 일부 `ㅖ`를 `ㅔ`로 발음합니다. |
> | `verbose` | `False` | `True`이면 적용된 규칙의 설명과 변환 전후를 출력합니다. |
> | `group_vowels` | `False` | `True`이면 요즘 화자들이 구분하지 않는 모음(`ㅐ/ㅔ`, `ㅒ/ㅖ`, `ㅙ·ㅞ/ㅚ`)을 하나로 통일합니다. |
> | `to_syl` | `True` | `False`이면 결과를 음절로 조합하지 않고 자모 상태로 반환합니다. |
>
> ### 규칙 확인하기 (`verbose`)
>
> ```python
> g2p("어제는 날씨가 맑았는데, 오늘은 흐리다.", verbose=True)
> ```
>
> 바뀐 부분마다 변환 전후와 해당 표준 발음법 조항이 붉은색으로 출력됩니다.
>
> ### 실제 발음 경향 반영하기 (`descriptive`)
>
> ```python
> g2p("우리의 의견", descriptive=True)
> ```
>
> ## 처리 과정
>
> 입력 문장은 다음 순서로 변환됩니다. `나의 친구가 mp3 file 3개를 다운받고 있다`를 예로 들면 다음과 같습니다.
>
> | 단계 | 처리 | 결과 |
> | --- | --- | --- |
> | 1 | 관용 표현 치환 (`idioms.txt`) | 나의 친구가 **엠피쓰리** file 3개를 다운받고 있다 |
> | 2 | 영어 → 한글 | 나의 친구가 엠피쓰리 **파일** 3개를 다운받고 있다 |
> | 3 | 형태소 분석으로 품사 표시 | 나의/J 친구가 엠피쓰리 파일 3개/B를 다운받고 있다 |
> | 4 | 숫자 읽기 | 나의/J 친구가 엠피쓰리 파일 **세**개/B를 다운받고 있다 |
> | 5 | 자모 분해 | (음절을 초성·중성·종성으로 분리) |
> | 6 | 특수 규칙 적용 | `ㅢ`·`ㅕ`·`ㅖ` 처리, 어간 받침 처리, 구개음화 등 |
> | 7 | 받침+초성 규칙표 적용 | 경음화, 비음화, 유음화 등 |
> | 8 | 연음 처리 | 받침이 뒤 음절의 모음으로 이어짐 |
> | 9 | 후처리 | 모음 통일(옵션), 음절 조합 |
>
> 최종 결과는 `나의 친구가 엠피쓰리 파일 세개를 다운받꼬 읻따`처럼 실제 소리나는 대로 표기됩니다.
>
> ## 프로젝트 구조
>
> ```
> g2pk/
> ├── g2pk.py       # G2p 클래스 (전체 파이프라인)
> ├── special.py    # ㅢ, ㅖ, 어간 받침, 구개음화 등 특수 규칙
> ├── regular.py    # 연음 등 일반 규칙
> ├── english.py    # 영어 → 한글 변환
> ├── numerals.py   # 숫자 → 한글 변환
> ├── utils.py      # 형태소 태깅, 자모 조합 등 공용 함수
> ├── table.csv     # 받침 × 초성 규칙표
> ├── rules.txt     # 표준 발음법 조항 및 예시 (verbose 출력에 사용)
> └── idioms.txt    # 관용 표현·예외 사전
> ```
>
> `idioms.txt`는 한 줄에 `원문===치환문` 형식으로 적으며(`#` 뒤는 주석), 정규식으로 처리되고 다른 규칙보다 먼저 적용됩니다.
> 특정 단어의 발음이 틀리게 나오면 이 파일에 줄을 추가해 바로잡을 수 있습니다.
>
> ## 한계
>
> - 규칙 기반이므로 형태소 분석이 틀리거나 사전에 없는 예외 단어는 잘못 변환될 수 있습니다.
> - 영어 변환은 CMU 발음 사전에 있는 단어에 한정됩니다.
> - 장단음(길이)은 표기하지 않습니다.

> # g2pK
>
> 한글 문장을 실제로 소리 나는 대로 적은 한글로 바꾸는 파이썬 패키지입니다. 표준 발음법의 규칙을 적용해 받침 발음, 연음, 경음화, 비음화 같은 변화를 반영하고, 문장에 섞인 영어 단어와 아라비아 숫자도 한글로 읽어 줍니다. g2p는 grapheme-to-phoneme, 곧 글자를 발음으로 바꾸는 작업을 뜻합니다.
>
> ```python
> from g2pk import G2p
>
> g2p = G2p()
> g2p("나의 친구가 mp3 file 3개를 다운받고 있다")
> # 나의 친구가 엠피쓰리 파일 세개를 다운받꼬 읻따
> ```
>
> ## 설치
>
> 저장소를 내려받아 설치합니다.
>
> ```bash
> git clone https://github.com/Kyubyong/g2pK.git
> cd g2pK
> pip install .
> ```
>
> Python 3.6 이상이 필요합니다. `jamo`, `nltk`, `konlpy`, `python-mecab-ko`가 함께 설치됩니다.
>
> 영어 단어를 한글로 바꿀 때 NLTK의 CMU 발음 사전(`cmudict`)을 씁니다. 사전이 없으면 `g2pk`를 처음 가져올 때 자동으로 내려받으므로, 이때는 네트워크 연결이 필요합니다.
>
> ## 사용법
>
> `G2p()`로 객체를 만들고 문자열을 넘기면 발음대로 적은 문자열을 돌려줍니다. 객체는 한 번 만들어 두고 계속 호출하면 됩니다.
>
> ```python
> g2p = G2p()
> g2p(string, descriptive=False, verbose=False, group_vowels=False, to_syl=True)
> ```
>
> | 인자 | 기본값 | 설명 |
> |---|---|---|
> | `descriptive` | `False` | `True`이면 표준 발음법이 허용하는 발음 가운데 실제 언어 사용에 가까운 쪽을 따릅니다. 일부 음절을 제외한 `ㅖ`는 [ㅔ]로, 조사 `의`는 [에]로, 첫음절이 아닌 `의`는 [이]로 읽습니다. |
> | `verbose` | `False` | `True`이면 규칙이 적용될 때마다 변환 전후와 해당 규칙의 조문을 출력합니다. |
> | `group_vowels` | `False` | `True`이면 같은 소리로 들리는 모음을 하나로 모읍니다. `ㅐ`→`ㅔ`, `ㅒ`→`ㅖ`, `ㅙ`·`ㅞ`→`ㅚ`로 바뀝니다. |
> | `to_syl` | `True` | `False`이면 결과를 음절로 조합하지 않고 자모 단위로 돌려줍니다. |
>
> ### 영어와 숫자
>
> 문장 안의 영어 단어는 CMU 발음 사전을 바탕으로 한글로 바꿉니다. 사전에 없는 단어는 바꾸지 않고 그대로 둡니다.
>
> 숫자는 뒤에 오는 단위에 따라 읽습니다. 형태소 분석기(MeCab)가 단위를 나타내는 의존 명사로 본 말 앞에서는 숫자를 풀어 씁니다. `개`, `마리`처럼 고유어 수사와 함께 쓰는 단위 앞에서는 `한`, `두`, `세`로, 그 밖의 단위 앞에서는 `일`, `이`, `삼`으로 씁니다. 그 외의 숫자는 한 자리씩 읽습니다. 고유어 수사와 함께 쓰는 단위의 전체 목록은 `g2pk/numerals.py`의 `BOUND_NOUNS`에 있습니다.
>
> ### 예외 단어 추가
>
> 규칙만으로 처리되지 않는 단어는 `g2pk/idioms.txt`에 한 줄에 하나씩 `원래 표기===바꿀 표기` 형식으로 적습니다. 이 파일의 항목은 다른 처리보다 먼저 적용되고, `#` 뒤는 주석입니다. 각 줄은 정규식으로 처리됩니다.
>
> ### 규칙 확인
>
> `verbose=True`로 호출하면 어떤 규칙 때문에 발음이 바뀌었는지 볼 수 있습니다. 규칙 조문은 `g2pk/rules.txt`에 있습니다.
>
> ```python
> g2p("나의 친구가 mp3 file 3개를 다운받고 있다", verbose=True)
> ```

> | 인자 | 설명 |
> |---|---|
> | `descriptive` | `True`이면 실제 언중의 발음 경향을 따릅니다. 일부 초성 뒤의 'ㅖ'를 'ㅔ'로, 조사 '의'를 '에'로, 단어의 첫음절 이외의 '의'를 '이'로 바꿉니다. 기본값 `False`에서는 이 변환을 하지 않습니다. |
> | `verbose` | `True`이면 규칙이 적용될 때마다 바뀌기 전후의 문자열과 적용된 규칙의 설명을 출력합니다. |
> | `group_vowels` | `True`이면 소리가 같은 모음을 하나로 모읍니다. 'ㅐ'는 'ㅔ'로, 'ㅒ'는 'ㅖ'로, 'ㅙ'와 'ㅞ'는 'ㅚ'로 바뀝니다. |
> | `to_syl` | 기본값 `True`에서는 결과를 음절 글자로 조합해서 돌려줍니다. `False`로 두면 조합하지 않고 자모 단위로 돌려줍니다. |
>
> ```python
> g2p("우리의 주의", descriptive=True)   # 실제 발음 경향 반영
> g2p("나의 친구가 있다", verbose=True)    # 적용된 규칙을 함께 출력
> g2p("나의 친구가 있다", group_vowels=True)
> g2p("나의 친구가 있다", to_syl=False)    # 자모 단위로 반환
> ```
>
> ### 영어와 숫자
>
> 문장에 섞인 영어 단어는 CMU 발음 사전을 거쳐 한글로 바뀝니다. 이 사전에 없는 단어는 바뀌지 않고 그대로 남습니다.
>
> 숫자는 뒤에 오는 단위에 따라 읽는 방식이 달라집니다. MeCab이 숫자 뒤의 말을 의존명사로 분석하면 숫자를 하나의 수로 읽습니다. `개`, `마리`, `권`처럼 고유어 수사와 함께 쓰는 단위 앞에서는 '세', '두' 같은 고유어 수사로, 그 밖의 단위 앞에서는 '십', '이십' 같은 한자어 수사로 읽습니다. 의존명사 앞이 아닌 숫자는 한 자리씩 읽습니다. 위의 `3개`가 `세개`가 되는 것이 그 예입니다.
>
> MeCab의 분석 결과가 입력 문자열과 맞지 않으면 품사 정보를 붙이지 못합니다. 이때는 조사·어미·의존명사에 따른 처리를 건너뜁니다.
>
> ### 관용 표현 사전 고치기
>
> `g2pk/idioms.txt`는 규칙만으로는 맞게 읽히지 않는 단어와 표기를 직접 지정하는 파일입니다. 입력 문자열에 가장 먼저 적용되며, 한 줄에 `바꿀 문자열===바뀔 문자열` 형식으로 적습니다. 왼쪽은 정규식으로 처리되고, `#` 뒤는 주석이며, 줄은 위에서 아래로 차례로 적용됩니다.
>
> ```
> mp3===엠피쓰리
> %===퍼센트
> 10월===시월
> ```
>
> 단어를 추가하려면 이 파일에 줄을 더하면 됩니다. 규칙마다 붙은 번호와 설명은 `g2pk/rules.txt`에 있고, `verbose=True`일 때 출력되는 설명도 여기서 가져옵니다.

> # g2pK: 한국어 G2P 모듈
>
> g2pK는 한글 문장을 **실제 발음 그대로 적은 한글**로 바꿔 주는 파이썬 패키지입니다.
> 표준 발음법의 규칙(연음, 경음화, 비음화, 유음화, 구개음화, ㅎ 탈락 등)을 적용하고,
> 문장에 섞인 영어 단어와 아라비아 숫자까지 한글 발음으로 풀어 줍니다.
>
> ```python
> >>> from g2pk import G2p
> >>> g2p = G2p()
> >>> g2p("나의 친구가 mp3 file 3개를 다운받고 있다")
> '나의 친구가 엠피쓰리 파일 세개를 다운받꼬 읻따'
> ```
>
> 음성 합성(TTS)이나 음성 인식 등에서 텍스트를 발음 표기로 바꾸는 전처리 단계로 쓰기 좋습니다.
>
> ## 주요 기능
>
> - **표준 발음법 적용**: `g2pk/rules.txt`에 정리된 한글 맞춤법 규정(표준 발음법)을 바탕으로 한 변환 규칙을 사용합니다.
> - **형태소 분석 기반 처리**: MeCab으로 품사를 확인해, 조사 '의'나 관형사형 어미 'ㄹ', 용언 어간의 받침 등 문맥에 따라 달라지는 발음을 구분합니다.
> - **영어 → 한글**: CMU 발음 사전(`cmudict`)을 이용해 영어 단어를 한글 발음으로 바꿉니다. (예: `file` → `파일`)
> - **숫자 → 한글**: 아라비아 숫자를 한자어 수(일, 이, 삼…) 또는 고유어 수(한, 두, 세…)로 읽어 줍니다. 뒤에 오는 단위에 따라 알맞은 쪽을 고릅니다.
> - **관용 표현 사전**: 규칙만으로 처리하기 어려운 단어(예: `발동` → `발똥`, `mp3` → `엠피쓰리`, `10월` → `시월`)는 `g2pk/idioms.txt`에서 먼저 치환합니다.
> - **변환 과정 확인**: `verbose=True`로 어떤 규칙이 적용되었는지 단계별로 볼 수 있습니다.
>

> # g2pK
>
> g2pK는 한국어 문장을 발음대로 적은 문장으로 바꾸는 파이썬 패키지입니다. 글자를 발음으로 바꾸는 g2p(grapheme-to-phoneme) 모듈이며, 표준 발음법의 규칙을 적용합니다. 문장에 섞인 영어 단어와 아라비아 숫자도 한글 발음으로 바꿉니다.
>
> ```python
> from g2pk import G2p
>
> g2p = G2p()
> g2p("나의 친구가 mp3 file 3개를 다운받고 있다")
> # 나의 친구가 엠피쓰리 파일 세개를 다운받꼬 읻따
> ```
>
> ## 설치
>
> 저장소를 내려받아 설치합니다.
>
> ```bash
> git clone https://github.com/Kyubyong/g2pK
> cd g2pK
> pip install .
> ```
>
> Python 3.6 이상이 필요하고, 설치할 때 `jamo`, `nltk`, `konlpy`, `python-mecab-ko`가 함께 설치됩니다. 형태소 분석에는 `python-mecab-ko`의 MeCab을 씁니다. `g2pk`를 처음 불러올 때 nltk의 `cmudict`가 없으면 자동으로 내려받으므로, 이때는 인터넷 연결이 필요합니다.
>
> ## 사용법
>
> `G2p()` 객체를 만들고 문자열을 넘기면 발음대로 바꾼 문자열을 돌려줍니다. 옵션은 모두 키워드 인자로 넘기며, 아래는 옵션별 호출 예입니다.
>
> ```python
> g2p("문장")                      # 표준 발음법 그대로 변환
> g2p("문장", descriptive=True)    # 실제 발음에 가깝게 변환
> g2p("문장", verbose=True)        # 변환 과정과 적용된 규칙을 출력
> g2p("문장", group_vowels=True)   # 구분하지 않는 모음을 하나로 통일
> g2p("문장", to_syl=False)        # 음절로 조합하지 않고 자모 상태로 반환
> ```
>
> `descriptive`, `verbose`, `group_vowels`의 기본값은 `False`이고 `to_syl`의 기본값은 `True`입니다.
>
> - `descriptive=True`: 표준 발음법이 허용하는 발음 중 실제로 많이 쓰이는 쪽을 따릅니다. 'ㅖ'를 'ㅔ'로(시계 → 시게), 단어 첫음절 이외의 '의'를 '이'로(주의 → 주이), 조사 '의'를 '에'로(우리의 → 우리에) 발음합니다. 예, 녜, 셰, 쎼의 'ㅖ'는 바꾸지 않습니다.
> - `verbose=True`: 변환이 일어난 단계마다 바뀌기 전후의 문자열과 적용된 표준 발음법 조항을 출력합니다. 조항은 빨간색(ANSI 이스케이프 코드)으로 표시됩니다.
> - `group_vowels=True`: 'ㅐ'를 'ㅔ'로, 'ㅒ'를 'ㅖ'로, 'ㅙ'와 'ㅞ'를 'ㅚ'로 바꿉니다.
> - `to_syl=False`: 결과를 한글 자모 낱글자 상태로 돌려줍니다.
>
> ## 변환 과정
>
> 입력은 다음 순서로 처리됩니다.
>
> 1. 예외 단어 치환: `g2pk/idioms.txt`에 적힌 단어와 표기를 먼저 바꿉니다. 합성어의 된소리나 ㄴ 첨가처럼 규칙만으로 정하기 어려운 단어(갈등 → 갈뜽, 솜이불 → 솜니불)와 `mp3` → `엠피쓰리` 같은 표기가 들어 있습니다. 한 줄에 `바꿀말===바뀐말` 형식으로 적고 정규식으로 처리하므로, 단어를 추가하려면 같은 형식으로 줄을 더하면 됩니다.
> 2. 영어 단어 변환: CMU 발음 사전(nltk `cmudict`)으로 영어 단어를 외래어 표기법에 따라 한글로 바꿉니다(`old school` → `올드 스쿨`). 사전에 없는 단어는 그대로 둡니다.
> 3. 형태소 분석: MeCab으로 조사 '의', 관형형 'ㄹ', 용언 어간, 의존명사를 표시해 둡니다.
> 4. 숫자 읽기: 단위를 나타내는 의존명사 앞의 숫자는 수사로 풀어 씁니다. `g2pk/numerals.py`의 목록에 있는 단위(개, 마리, 시 등) 앞에서는 고유어 수사(한, 두, 세…)로, 그 밖의 단위 앞에서는 한자어 수사(일, 이, 삼…)로 읽습니다. 나머지 숫자는 한 자리씩 영, 일, 이…로 바꿉니다.
> 5. 발음 규칙 적용: 모음 규칙, 어간 받침 규칙, 받침과 초성의 조합표(`g2pk/table.csv`), 연음 규칙을 차례로 적용합니다.
>
> ## 한계
>
> - 형태소 분석 결과를 입력 문자열과 맞출 수 없으면 품사 표시 없이 진행합니다. 이때 품사 표시가 필요한 규칙(조사 '의', 관형형 'ㄹ' 뒤와 용언 어간 받침 뒤의 된소리)이 적용되지 않고, 단위 의존명사 앞 숫자도 한 자리씩 읽습니다.
> - 영어 단어는 CMU 발음 사전에 있는 단어만 바뀌며, 발음이 여러 개 등록된 단어는 첫 번째 발음을 씁니다.

### 글빨 0.4.1 — ○ 근거 판정 통과

> # g2pK
>
> g2pK는 한국어 문장을 소리 나는 대로 적은 한글로 바꾸는 파이썬 모듈입니다. G2P(grapheme-to-phoneme)는 글자를 발음으로 바꾸는 작업을 뜻합니다. 입력에 섞인 영어 단어와 아라비아 숫자도 한글로 읽어 줍니다.
>
> ```python
> from g2pk import G2p
>
> g2p = G2p()
> g2p("나의 친구가 mp3 file 3개를 다운받고 있다")
> # '나의 친구가 엠피쓰리 파일 세개를 다운받꼬 읻따'
> ```
>
> ## 설치
>
> 저장소를 받아 그 폴더에서 설치합니다.
>
> ```bash
> pip install .
> ```
>
> 설치되는 의존 패키지는 `jamo`, `nltk`, `konlpy`, `python-mecab-ko`입니다. Python 3.6 이상이 필요합니다.
>
> `g2pk`를 처음 불러올 때 NLTK의 `cmudict` 말뭉치가 없으면 `nltk.download('cmudict')`로 내려받습니다. 이때 네트워크 연결이 필요합니다. 영어 단어를 한글로 바꾸는 데 이 사전을 씁니다.
>
> ## 사용법
>
> `G2p()` 객체를 만든 뒤 문자열을 넘기면 변환된 문자열을 돌려줍니다.
>
> ```python
> g2p = G2p()
> g2p("나의 친구가 mp3 file 3개를 다운받고 있다")
> ```
>
> 한 문장은 다음 순서로 처리됩니다.
>
> 1. `idioms.txt`에 적힌 표현을 바꿉니다. 예를 들어 `mp3`는 `엠피쓰리`가 됩니다.
> 2. 영어 단어를 CMU 발음 사전으로 한글로 바꿉니다. 사전에 없는 단어는 그대로 둡니다.
> 3. 형태소 분석기(MeCab)로 품사를 붙입니다.
> 4. 숫자를 한글로 읽습니다. `개`, `시`처럼 고유어 수사와 함께 쓰는 의존 명사 앞에서는 `세`, `열` 같은 고유어 수사로, 그 밖의 의존 명사 앞에서는 `일`, `십` 같은 한자어 수사로 읽습니다. 뒤에 의존 명사가 없는 숫자는 한 자리씩 읽습니다.
> 5. 특수 규칙, 받침과 첫소리의 결합 규칙(`table.csv`), 연음 규칙을 차례로 적용합니다.
>
> ### 옵션
>
> 호출할 때 다음 인자를 줄 수 있습니다.
>
> | 인자 | 기본값 | 설명 |
> |---|---|---|
> | `descriptive` | `False` | `True`이면 실제 발음에 가까운 변환을 켭니다. 'ㅖ'를 'ㅔ'로, 조사 '의'를 '에'로, 단어 첫음절 이외의 '의'를 '이'로 바꿉니다. |
> | `verbose` | `False` | `True`이면 규칙이 적용될 때마다 변환 전후와 해당 규칙의 설명을 출력합니다. |
> | `group_vowels` | `False` | `True`이면 소리가 같아진 모음을 하나로 모읍니다. 'ㅐ'는 'ㅔ'로, 'ㅒ'는 'ㅖ'로, 'ㅙ'와 'ㅞ'는 'ㅚ'로 바꿉니다. |
> | `to_syl` | `True` | `False`이면 결과를 음절로 조합하지 않고 자모 단위로 돌려줍니다. |
>
> ```python
> g2p("나의 친구가 mp3 file 3개를 다운받고 있다", descriptive=True)
> g2p("나의 친구가 mp3 file 3개를 다운받고 있다", verbose=True)
> g2p("나의 친구가 mp3 file 3개를 다운받고 있다", group_vowels=True, to_syl=False)
> ```
>
> ## 알아 둘 점
>
> - 형태소 분석 결과를 이어 붙인 글자가 입력과 같지 않으면 품사 표시를 붙이지 않습니다. 이 경우 품사에 기대는 규칙(조사 '의', 용언 어간 받침, 관형사형 어미 'ㄹ', 의존 명사 앞 숫자)은 적용되지 않습니다.
> - 영어 단어는 알파벳과 아포스트로피로 이뤄진 덩어리 단위로 찾아 CMU 발음 사전의 첫 번째 발음으로 바꿉니다. 사전에 없는 단어는 바뀌지 않습니다.
> - `idioms.txt`는 한 줄에 `바꿀 문자열===바뀐 문자열` 형식으로 적으며, 정규 표현식으로 처리됩니다. 사전에 없는 어휘의 읽기를 고치려면 이 파일에 줄을 추가합니다.
