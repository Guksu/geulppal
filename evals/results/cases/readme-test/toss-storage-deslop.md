## 원문

> # @toss/storage
>
> **시크릿 모드에서 `localStorage`에 접근했다가 에러를 만난 적이 있나요?**
>
> 브라우저의 시크릿 모드나 테스트 환경처럼 Web Storage를 사용할 수 없는 환경에서 `localStorage`나 `sessionStorage` 등에 접근하면 에러가 발생합니다. 이런 예외 상황은 예상하지 못한 순간에 애플리케이션을 멈추게 하고, 개발자에게는 방어 코드를 계속 덧붙이는 부담을 안깁니다.
>
> `@toss/storage`는 이 문제를 해결하기 위해 만들어진 라이브러리입니다. Web Storage를 쓸 수 없는 환경에서도 에러 없이 안정적으로 동작하므로, 환경에 따른 예외 처리를 일일이 신경 쓰지 않고 스토리지를 사용할 수 있습니다.
>
> 여기에 더해 `@toss/storage/typed`를 사용하면 스토리지에 저장된 값을 타입 안전하게 다룰 수 있습니다. 더 견고하고 예측 가능한 코드를 작성하고 싶다면 함께 활용해 보세요.
