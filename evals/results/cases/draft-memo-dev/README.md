# 사례별 결과: 메모로 쓰는 업무 글 개발용

[← 벤치마크 개요](../../README.md)

사례 이름을 누르면 요청, 메모, 조건별 결과, 판정 이유를 볼 수 있습니다. 근거 판정 칸은 조건마다 통과한 회차 수입니다(글빨 없음 · 글빨 0.4.1 · 0.4.2-r1 후보).

| 사례 | 작업 | 근거 판정 통과<br>(없음 · 0.4.1 · 0.4.2-r1) | 없음 vs 0.4.1 | 0.4.1 vs 0.4.2-r1 | 사람 vs 0.4.1 |
|---|---|---|---|---|---|
| [`ramsar-press`](ramsar-press.md)<br>보도자료 | 새 글 작성 | 0/2 · 2/2 · 1/2 | 제외 · 제외 | 같음 · 제외 | 0.4.1 · 0.4.1 |
| [`vaccine-leave-notice`](vaccine-leave-notice.md)<br>안내문 | 새 글 작성 | 0/2 · 1/2 · 1/2 | 제외 · 제외 | 제외 · 제외 | - · - |
| [`ghg-report`](ghg-report.md)<br>보고서 | 새 글 작성 | 0/2 · 2/2 · 2/2 | 제외 · 제외 | 0.4.2-r1 · 0.4.2-r1 | - · - |
| [`fintech-sandbox-brief`](fintech-sandbox-brief.md)<br>보고서 | 새 글 작성 | 1/2 · 2/2 · 2/2 | 엇갈림 · 제외 | 같음 · 엇갈림 | - · - |

품질 비교 칸은 회차별 결과입니다. 이름이 적힌 쪽이 우세, `같음`은 차이 없음, `엇갈림`은 순서를 바꾸면 판정이 바뀐 경우, `제외`는 한쪽 이상이 근거 판정에 실패해 비교하지 않은 경우입니다.

자동으로 만든 페이지입니다. 판정은 모두 모델(`claude-opus-5-5`)이 했고 사람의 평가가 아닙니다.
