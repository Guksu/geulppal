## 원문

> # 체크인봇
>
> 체크인봇은 팀의 일일 체크인을 혁신적으로 바꾸는 강력한 슬랙 봇입니다. 오늘날 원격 근무 환경에서 팀원 간의 소통은 그 어느 때보다 중요해지고 있습니다. 체크인봇은 이러한 소통의 문제를 해결하기 위해 탄생했습니다.
>
> ## 주요 기능
>
> 체크인봇은 매일 정해진 시간에 팀원에게 체크인 질문을 보냅니다. 답변은 지정한 채널에 모아서 게시합니다. 이를 통해 팀은 서로의 진행 상황을 한눈에 파악할 수 있으며, 이는 팀의 생산성 향상에 중요한 역할을 합니다. 주말과 공휴일에는 질문을 보내지 않습니다. 단, 공휴일 목록은 한국 기준만 지원합니다.
>
> ## 설치
>
> Node.js 20 이상이 필요합니다.
>
> ```bash
> npm install
> cp .env.example .env
> npm start
> ```
>
> `.env`에 `SLACK_BOT_TOKEN`과 `CHECKIN_CHANNEL_ID`를 넣어야 합니다. 질문 시간은 `CHECKIN_TIME`(기본값 `09:30`)으로 바꿀 수 있습니다.
>
> ## 왜 체크인봇인가?
>
> 체크인봇을 사용하면 매일 정해진 시간에 질문을 받고, 답변이 채널에 자동으로 모입니다. 팀원 모두가 서로의 진행 상황을 한눈에 볼 수 있습니다. 체크인봇과 함께 더 나은 팀 문화를 만들어 보세요.
>
> ## 마치며
>
> 체크인봇은 팀 소통의 새로운 기준이 될 것입니다. 지금 바로 설치해서 혁신적인 체크인 경험을 시작하세요!
