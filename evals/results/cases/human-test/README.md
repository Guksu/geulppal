# 사례별 결과: 사람이 쓴 글: 확인용

[← 벤치마크 개요](../../README.md)

스킬을 고정한 뒤 처음 돌린 사례입니다. polish는 사람이 쓴 원문을 그대로 다듬어 달라는 요청이고, deslop은 다른 모델이 부풀린 글에서 AI 티를 빼 달라는 요청입니다. 사람 원문(H)은 polish에서는 입력과 같은 글, deslop에서는 부풀리기 전의 원문입니다. 원문 출처는 [sources.json](../../../human/sources.json)에 있습니다.

사례 이름을 누르면 요청, 원문, 조건별 결과, 판정 이유를 볼 수 있습니다. 의미 보존 칸은 조건마다 통과한 회차 수입니다(글빨 없음 · 글빨 0.2.1 · 글빨 0.3.0 · 사람 원문).

품질 비교 칸은 회차별 결과입니다. 이름이 적힌 쪽이 우세, `같음`은 차이 없음, `엇갈림`은 순서를 바꾸면 판정이 바뀐 경우, `제외`는 한쪽 이상이 의미 보존에 실패해 비교하지 않은 경우입니다.

자동으로 만든 페이지입니다. 판정은 모두 모델(`claude-opus-5-5`)이 했고 사람의 평가가 아닙니다.
