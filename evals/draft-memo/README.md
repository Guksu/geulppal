# 메모로 쓰는 업무 글 평가

보고서·보도자료·안내문은 보통 메모나 수치가 든 사실 목록을 주고 써 달라고 한다. 여기서는 작성 모델에게 요청과 메모만 주고 보도자료·안내문·보고서·기획서를 처음부터 쓰게 한다.

## 만드는 방법

1. **기사**: 대한민국 정책브리핑의 정책뉴스 가운데 2018~2022년에 게시되고 공공누리 제1유형(출처표시) 표시가 있는 기사 13편. 본문 텍스트만 쓰고 사진·표·사진 설명은 뺐다.
2. **메모**: 스킬 없는 별도 세션(`claude-sonnet-5-5`)이 기사를 담당자가 쓰기 전에 가졌을 법한 업무 메모로 되돌린다. 기관, 날짜, 수치와 단위, 대상, 조건·예외, 절차, 연락처, 발언자와 발언 요지를 짧은 항목으로 적고, 기사에 없는 해석은 넣지 않는다.
3. **메모 검수**: 판정 모델(`claude-opus-5-5`)이 기사와 메모를 대조한다([`memo-check.md`](../judge/memo-check.md)). 빠지거나 바뀌거나 더해진 사실이 있으면 다시 만든다(세 번까지). 13편 모두 통과했다(2편은 두 번째 시도).
4. **요청**: 같은 메모로 문서 종류를 정해 써 달라고 한다. 보도자료 4개, 안내문 5개, 보고서 3개, 기획서 1개다.
5. **기준 조건 H**: 보도자료 사례에서만 원래 기사를 사람 글로 둔다. 안내문·보고서·기획서는 기사와 장르가 달라 사람 글과 비교하지 않는다.

```bash
node scripts/eval/memo.mjs sources --dir evals/draft-memo   # 기사 가져오기
node scripts/eval/memo.mjs memo --dir evals/draft-memo      # 메모 만들기와 검수
node scripts/eval/memo.mjs build --dir evals/draft-memo     # 사례 만들기
```

## 판정

- **근거 판정**([`draft-memo-claims.md`](../judge/draft-memo-claims.md)): 메모가 유일한 근거다. 결과의 주장(이름, 날짜, 수치, 대상, 조건, 절차, 연락처, 발언, 목적·효과·전망, 향후 계획)마다 메모에서 근거를 찾는다. README 판정과 달리 근거 없는 기대 효과·전망·당부도 실패로 센다. 메모에 없는 일반론을 붙이는 것이 업무 글의 대표적인 문제이기 때문이다.
- **품질 비교**([`draft-memo-quality.md`](../judge/draft-memo-quality.md)): 문서 종류마다 독자가 찾는 것(보도자료는 무엇이 언제 바뀌는지, 안내문은 대상·기한·할 일·문의처, 보고서는 결론과 핵심 수치)을 앞에서 찾을 수 있는지 본다.

기사 주소와 본문은 [`sources.json`](sources.json)에 있다. 기사는 공공누리 제1유형(출처표시) 조건에 따라 출처를 밝혀 쓴다. 출처: 대한민국 정책브리핑(www.korea.kr).

개발용으로만 스킬을 고친다. 새 확인용은 개선을 마칠 때까지 결과를 보지 않는다.

한계:

- 메모는 기사에서 거꾸로 만든 것이라 실제 담당자의 메모보다 정리되어 있고, 기사의 순서를 따른다.
- 정책 기사라서 공공기관 문서에 치우쳐 있다. 회사 내부 보고서나 기획서는 없다.
- 2022-11-30 이후에 게시된 글은 쓰지 않았지만, 사람이 썼다고 확인할 방법은 없다.
